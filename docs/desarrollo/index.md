El hilo conductor es **Cuaderno**, una aplicación de notas con título y contenido. Primero comprenderemos los datos y dibujaremos una pantalla; después añadiremos edición, navegación, consulta de publicaciones remotas y almacenamiento local. No necesitas crear una aplicación nueva para cada concepto.

Los fragmentos de teoría aíslan una responsabilidad y señalan su contexto. El proyecto guiado contiene la configuración, los imports y las clases que colaboran para construir la aplicación completa. Mantén las [versiones comunes del curso](../recursos/index.md): mezclar el código de una versión con dependencias de otra dificulta localizar errores.
