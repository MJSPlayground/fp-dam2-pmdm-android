# Diseño visual avanzado, recursos y accesibilidad

**Ampliación.** Partimos de formularios, estado y navegación de [Compose](../desarrollo/compose.md). Construiremos una galería que cambia con el espacio disponible, presenta imágenes y mantiene su uso mediante teclado, lector de pantalla y tamaños de texto grandes.

El proyecto incorpora ilustraciones vectoriales originales y una captura propia que se carga por HTTPS. La navegación y los filtros se pueden probar sin red con las ilustraciones locales. El refresco del catálogo es una simulación para estudiar su estado visual, no una consulta a un backend.
