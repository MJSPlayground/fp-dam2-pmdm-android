# Firebase: backend y almacenamiento en la nube

**Ampliación.** Parte de HTTP, estado y persistencia del itinerario principal. Firebase proporciona servicios administrados; no elimina la necesidad de diseñar datos, permisos y recuperación de errores.

- [Configuración y laboratorio local](configuracion.md).
- [Cuentas y autenticación](autenticacion.md).
- [Documentos y actualizaciones en tiempo real](documentos.md).

- [Práctica guiada: notas privadas](practica.md).

El ejemplo ejecutable usa Emulator Suite de Firebase: cuentas, documentos y archivos reales del emulador, sin proyecto de producción ni facturación. La configuración de un servicio en la nube se estudia por separado; no hace falta activarlo para completar la práctica.
