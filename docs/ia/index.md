# Inteligencia artificial en aplicaciones Android

**Ampliación.** Utiliza estado, corrutinas, HTTP y selección de imágenes del itinerario principal. Una aplicación con IA sigue necesitando controles de entrada, privacidad y un recorrido de error comprensible.

- [Elegir entre nube y dispositivo](modelos.md).
- [Integración segura y contrato de generación](integracion.md).
- [Imagen, privacidad y verificación](multimodal.md).
- [Práctica guiada: consulta con texto e imagen](practica.md).
- [Consolidación y repaso](repaso.md), con [soluciones](soluciones.md).

El laboratorio incluye un servidor local con un modo simulado claramente identificado y un adaptador de generación remota configurable. El modo simulado permite comprobar la aplicación sin gastar cuota ni enviar fotografías a un proveedor. No se presenta como inferencia de un modelo.
