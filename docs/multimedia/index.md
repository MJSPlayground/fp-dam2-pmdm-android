Trabajaremos con cuatro laboratorios acotados: editor de imágenes, reproductor, mapa de lugares y notificación local. Cada uno permite observar una función del dispositivo sin obligar a reunir todo en una aplicación grande. Se parte de Kotlin, Compose, estado y ciclo de vida explicados en el [tema de desarrollo](../desarrollo/index.md).

El emulador permite repetir muchas situaciones, pero no reproduce todos los sensores, cámaras, radios ni decisiones del fabricante. Distingue siempre una entrada simulada de una lectura física y una compilación correcta de una interacción comprobada.

Las [prácticas guiadas](practica-imagenes.md) alternan ejemplos y tareas. Al terminar, realiza la [consolidación autónoma](consolidacion.md) y el [repaso](repaso.md).
